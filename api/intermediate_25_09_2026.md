## API — средний уровень

🏆 Правильных ответов: 12 из 12

#### Q1. Какой статус наиболее уместен при успешном создании ресурса через POST?

- [x] `201 Created`


#### Q2. Нужно отправить POST с JSON в curl. Какой вариант корректен?

- [x] `curl -X POST https://api.example.com/items -H "Content-Type: application/json" -d '{"name":"pen"}'`

#### Q3. Вы разрабатываете API, которому требуется защита передаваемых данных. Какой метод аутентификации вы выберете, если нужно хешировать логин и пароль перед отправкой, но не использовать токены или управление сессиями?

- [x] `Digest Authentication`

#### Q4. В API реализована ролевая модель. Какой HTTP код вернуть, если пользователь аутентифицирован, но не имеет прав на ресурс?

- [x] `403 Forbidden`

#### Q5. Клиент отправил PATCH /documents3, но ресурс находится в процессе обработки и временно не может быть изменён (операция должна быть повторена позже). Какой код выбрать?

- [x] `423 Locked`

#### Q6. Какой метод лучше использовать для "получить текущую версию ресурса" без побочных эффектов?

- [x] `GET /releases/current`

#### Q7. Ваш API используется для управления профилями пользователей. Один из клиентов отправил PUT-запрос для обновления имени пользователя {username}, но не указал существующий email. После выполнения запроса поле email в профиле стало пустым.  

Какой метод или процедура вызвали эту проблему?

- [x] `Использование метода PUT без указания неизменяемых полей ресурса`

#### Q8. Какой сценарий лучше всего объясняет, почему cursor-пагинация устойчивее при добавлении новых записей?

- [x] `Потому что курсор привязан к последнему полученному элементу в фиксированном списке`

#### Q9 Какой вариант контракта лучше всего поддерживает "асинхронный запуск + последующее получение результата" в REST-стиле?

- [x] `POST /jobs возвращает 202 + Location: /jobs/{id}, затем GET /jobs/{id} и GET /jobs/{id}/result`

#### Q10. Нужно автоматически сгенерировать документацию API из коллекции запросов, которую ведёт команда. Какой инструмент чаще используют для публикации документации из Postman?

- [x] `Postman Documentation`

#### Q11. Какой формат обычно считается более "человеко-читаемым" для конфигураций за счёт минимального количества скобок и кавычек

- [x] `YAML`

#### Q12. Какое ключевое свойство JWT упрощает аутентификацию в распределённой архитектуре с несколькими сервисами?

- [x] `JWT не требует хранения состояния на стороне сервера и позволяет сервисам проверять токен самостоятельно`
